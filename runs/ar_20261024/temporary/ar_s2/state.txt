# Noise Floor Data

Empirical same-code repeat measurements used by the multi-seed promotion gate.

- pair 1: 1.192708 (GPU 1) vs 1.195744 (GPU 0), |delta| = 0.003036 — identical code and seed, two identical GPUs; run-to-run hardware/kernel nondeterminism
- pair 2: 1.192527 (GPU 1) vs 1.188308 (GPU 1), |delta| = 0.004219 — identical code, seed 42 vs 43 (same GPU). Momentum experiment's multi-seed confirmation.
- pair 3: 1.169258 (GPU 0) vs 1.164542 (GPU 1), |delta| = 0.004716 — identical code, seed 42 (GPU0) vs seed 43 (GPU1). Cross-GPU + cross-seed repeat.

Pooled same-code sigma across 3 pairs = **0.002865** (2-sigma band ~0.0057).

Practical guidance: an experiment whose |delta| is below ~0.006 must be confirmed on a
second seed before promotion. Same-code repeat noise is ~0.003-0.005, i.e. 2-3x the
conservative 0.0015 default.
